# EL ESPEJO DE REX -- los numeros que estan escritos DOS veces.
#
# `bmo-abi` los declara en Rust y las cabeceras de `<bmo/...>` los repiten en C,
# porque C no puede importar de Rust. `<bmo/paquete.h>` ya lo confesaba: *"si
# algun dia dejan de coincidir, la fila de pruebas ... es la que lo dice"* -- y
# eso cubria UNA fila de las 90.
#
# ** Es el patron que ya costo caro: una tabla con dos lectores, y crecer por
# uno la rompe para el otro. El 22-08 fueron `intrinsics.toml` y cinco frontends.
#
# == Por que una TABLA y no una comparacion en vivo ==
#
# Comparar los dos lados hoy diria que coinciden. Lo que NO diria es que alguien
# cambio el numero **en los dos a la vez**: seguirian coincidiendo, y ese es
# justo el cambio que rompe los `.bex` que ya estan firmados. Contra el numero
# SELLADO no hay forma de que pase.
#
# == Lo que esta tabla NO puede decir ==
#
# **Si la pareja es la correcta.** Que `TASK_OP_FRAMEBUFFER_CLAIM` y
# `BMO_OP_PANTALLA_RECLAMAR` sean la misma cosa lo dice una PERSONA, aqui, en la
# nota. Una herramienta que lo dedujera estaria adivinando -- y un guardian que
# adivina da permiso con autoridad. Misma frontera que `LINEA_BASE.txt`.
#
# Formato:  numero  nombre_abi  nombre_c  nota
# Se regenera con `--sellar`, que CONSERVA las notas de las filas que no cambian.
