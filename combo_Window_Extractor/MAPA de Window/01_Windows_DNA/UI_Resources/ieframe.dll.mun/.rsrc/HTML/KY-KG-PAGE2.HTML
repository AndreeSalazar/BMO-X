Башкы бетиңизди жана издөө орнотууларыңызды тандаңыз

Ушул учурдан баштап Internet Explorer веб-сайттардын бул орнотууларды билдирбестен өзгөртүүсүн токтотот. Орнотууларды сактап калууну кааласаңыз, аларды тандаңыз.

Көбүрөөк маалымат алууга, бул жерди чыкылдатыңыз.
