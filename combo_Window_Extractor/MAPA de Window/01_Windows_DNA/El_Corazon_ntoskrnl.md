# El Corazón de Windows: Anatomía de `ntoskrnl.exe` y `hal.dll`

Este documento representa la extracción TOTAL y global del núcleo ejecutivo de Windows (Ring 0). Toda la arquitectura del kernel NT (la misma que clona ReactOS) está documentada aquí. Si BMO alguna vez quiere implementar una **Capa de Compatibilidad de Drivers (Wrapper)** para cargar `.sys` nativos de Windows, este es el mapa de funciones que tendría que emular.

**Total de APIs Expuestas por el Kernel analizadas:** 3352

---
