# Superficie API Mínima (Ejecución Nativa BMO)

A continuación se presentan las funciones **NATIVAS** organizadas lógicamente. Toda la basura legacy (Comm, Dos, Tape, LZ) ha sido eliminada. Estas son las funciones que FastOS debe implementar en Rust para que aplicaciones como OBS corran directamente en BMO.

- **Total funciones analizadas en el Cuarteto Básico:** 5301
- **Funciones basura (Legacy) eliminadas:** 118
- **Funciones Nativas (Núcleo Puro BMO):** 5183
